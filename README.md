# Test Gith

Petit projet web statique prêt à être publié depuis le dossier `public`.

## Contenu

- `public/index.html` : page d’accueil.
- `public/assets/css/style.css` : mise en page et design.
- `public/assets/js/main.js` : interaction légère.

## Déploiement Git

Le dépôt contient aussi un `index.html` à la racine pour un déploiement GitHub Pages standard. Vous pouvez publier la racine du dépôt directement, ou utiliser le dossier `public` si votre hébergement préfère cette structure.
